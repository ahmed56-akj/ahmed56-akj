Customer Churn Prediction Project
This project predicts whether a customer will leave (churn) or stay with a company based on their details, such as age, subscription length, monthly charges, payment method, and customer support interactions.

How It Works:
Data Processing:

We use customer data and convert categorical values (like gender and payment method) into numerical form.
The data is standardized to improve model performance.
Model Training:

A Random Forest Classifier is trained on the processed data.
The model learns patterns from past customer behavior to predict churn.
Web App with Flask:

Users enter customer details into a web form.
The app processes the input, applies the trained model, and predicts whether the customer will churn or stay.
Output & Results:

The prediction is displayed on the website.
Accuracy and performance are evaluated using metrics like classification reports and confusion matrices.
